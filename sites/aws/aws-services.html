대시보드 3개가 AWS 를 쓰는 방식

• 공통 정의 dashboard/aws_site.py — CloudFormation duckcloud-compute 출력에서 vm1 · vm2 ID 를 읽고, ctl 메쉬 이름표(hs.example.org/join/names.json)로 지금 AWS 가 운영 중인지 확인

• AWS CLI 프로필 aws-agent · 리전 ap-southeast-2 — Mac 의 aws login 세션으로 호출 (키를 파일에 두지 않음)

• 5050 통합 관제: 노드 카드 · 전원 ON/OFF(2대 함께) · vm2 MySQL 가동/정지(SSM)

• 5051 AWS 관리 대시보드: 기능별 과금 ON/OFF · 시연 모드(2대) · 전체 절전(AWS 가 운영 중이면 거부) · 과금 명세 · 이 페이지

• 5052 VM 터미널: AWS 노드는 SSH 대신 SSM Run Command 로 명령 실행 (보안 그룹에 22 없음)

• 판정 · 승격 · 복귀는 대시보드가 하지 않음 — ctl duck-hsagent (mesh.py · provision.py)
